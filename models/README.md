# Models Directory

This directory is intended for storing trained model checkpoints (e.g., PyTorch `.pth` files or unzipped model directories like `resnet50_best/` and `vit_b16_best/`). 

Note that the trained checkpoints are generated by running the training notebooks in the `notebooks/` directory.

Due to file size limits and best practices, large model checkpoints are not included in this GitHub repository and have been excluded via `.gitignore`.
